# candid docs — topic index

Your data lives in `candid_data/` (git-ignored) on your own machine; sample
data lives in `samples/candid/` so you can try every command in minutes.

- [onboarding](onboarding.md) — Ingest your resume and LinkedIn export into a structured profile.
- [matching](matching.md) — Score any job description against your profile.
- [tailoring](tailoring.md) — Generate tailored resumes and cover letters for a job.
- [tracking](tracking.md) — Add, list, update, and get stats on your applications.
- [prep](prep.md) — Build an interview prep pack for a company and role.
- [mock](mock.md) — Practice: coding judge, AI interviewer, behavioral, system design.
- [salary](salary.md) — Look up pay ranges and import DOL H-1B LCA data.
- [offers](offers.md) — Record offers and compare total compensation.
- [jobs](jobs.md) — Discover curated open jobs and feed them into your tracker.
- [dashboard](dashboard.md) — Run the local web dashboard (127.0.0.1 only).
- [imports](imports.md) — Import your own data exports (Gmail Takeout mbox, LinkedIn ZIP).
- [followup](followup.md) — Draft thank-you, check-in, and referral emails.
- [negotiate](negotiate.md) — Negotiation playbook, scenario scripts, and counter drafts.
- [glossary](glossary.md) — Job-search and candid terms, defined in one place.
- [faq](faq.md) — Frequently asked questions.
- [tutorial](tutorial.md) — End-to-end walkthrough: onboard -> jobs -> match -> tailor -> track -> prep -> mock -> followup.

Tip: run `python -m candid <command> --help` for full flag details on any command.
